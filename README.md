# Git Command Learning Hub

A beginner-friendly educational website designed to help students learn essential Git commands through simple explanations, practical examples, and guided demonstrations.

## Core Features

- Git command reference
- Live command search and filtering
- Interactive Git command simulator
- Beginner-friendly explanations
- Responsive website design

## Git Commands Covered

- `git init`
- `git add`
- `git commit`
- `git push`
- `git status`

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub
